# 实验八迁移边界（8.1 身份、8.2 商品读）

8.2 沿用“只支持全新环境”的限制。新增 `product_read_db` 仅保存商品搜索投影、Inbox、索引待办和重建状态；`market_db` 继续拥有商品、库存、订单、支付、售后和质保交易事实。市场事务写入完整源快照 Outbox，读侧事件投影可用保留事件 replay 和在线索引重建恢复。第三库不是交易表的主库副本，不能把搜索状态用于决定可售库存或订单金额，也不能复用实验七或 8.1 的 Flyway 历史伪装成迁移。三组 app/migrator 最小权限账号相互拒绝跨库读取。

## 8.1 身份迁入的历史限制

本实验只支持全新环境，不支持生产不停机迁移。实验七的 HS256 Token、单库数据与 Flyway 历史不能直接交给实验八使用。不要把旧数据库改名后当作已完成身份拆分。

身份服务拥有 `identity_db` 的用户、邮箱验证和外部身份映射；兼容业务单体拥有 `market_db` 的商品、订单、支付、售后和质保事实。两个应用使用独立账号，账号权限只限本库，跨库访问应由 MySQL 拒绝。业务表保存身份 UUID，不建立跨库外键，不通过身份库查询补足业务事务。

身份服务持有 RSA 私钥，Gateway 和兼容单体只读取 JWKS 公钥。Access Token 使用 RS256，固定 15 分钟，两层分别校验签名及身份契约。生产密钥通过外部配置注入，不沿用实验七共享 HMAC 密钥，不将测试密钥装入生产包。

若以后需要迁移真实数据，必须单独设计用户 ID 保持、密码哈希兼容、双写及补放、Token 过渡、回滚与切流验证。上述步骤不属于本次 8.1 实现与验收范围。
